# Shanthi Beds Website

A responsive business website developed for **Shanthi Beds**, a mattress and furniture business.

## Project Overview

This project was developed as a client website to provide customers with information about the business, products, and contact options through a simple and user-friendly web interface.

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Google Sheets
* Google Apps Script
* WhatsApp Integration

## Key Features

* Responsive website design
* Product information and presentation
* Contact/enquiry form
* Form data connected to Google Sheets
* WhatsApp enquiry integration
* User-friendly navigation
* Mobile-friendly interface

## My Contribution

* Designed and developed the website
* Created the website structure using HTML
* Styled the pages using CSS
* Added interactive functionality using JavaScript
* Integrated form submissions with Google Sheets
* Implemented WhatsApp enquiry functionality
* Tested the website across different screen sizes
